# Sentinel AI — Autonomous Cyber Defense Simulator

An **AI-powered MERN cybersecurity simulation platform** that recreates a **Security Operations Center (SOC)** environment for real-time threat detection, incident response, and security monitoring. Sentinel AI enables users to simulate cyber defense scenarios, analyze security events, and monitor network activity through a live interactive dashboard.

## Key Highlights

* Built a **real-time SOC dashboard** with live security alerts and threat monitoring.
* Implemented **WebSocket-based event streaming** for instant dashboard synchronization.
* Developed **JWT-secured authentication and role-based access control**.
* Designed **Dockerized simulation services** for isolated security event generation.
* Created **log analysis and incident-response workflows** for monitoring and investigation.
* Built a **scalable MERN architecture** supporting modular backend services and real-time analytics.

## Tech Stack

**Frontend:** React.js, Tailwind CSS
**Backend:** Node.js, Express.js, MongoDB
**Real-time:** Socket.io
**Authentication:** JWT
**DevOps:** Docker, Docker Compose

## System Architecture

Sentinel AI follows a **modular MERN architecture** where authentication, simulation management, event processing, and monitoring services operate independently. Security events are generated by simulation services, stored in MongoDB, and streamed to the dashboard through **WebSockets**, enabling real-time visualization of alerts and incident activity.

## Run Locally

```bash
git clone https://github.com/Divya-a-wq/Autonomous-cyber-defense-simulator.git
cd Autonomous-cyber-defense-simulator
```

### Install Dependencies

```bash
# Backend
cd server
npm install

# Frontend
cd ../client
npm install
```

### Configure Environment Variables

Create a **.env** file inside the **server** directory.

```env
PORT=5000
MONGODB_URI=mongodb://localhost:27017/sentinel-ai
JWT_SECRET=your_secret_key
```

### Start Docker Services

```bash
docker compose up -d
```

### Run the Application

```bash
# Backend
cd server
npm run dev

# Frontend
cd client
npm run dev
```
